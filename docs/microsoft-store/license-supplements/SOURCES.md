# Supplemental Cargo license texts

These files fill license-text gaps in six locked Windows x64 crates whose published source archives do not contain a license text. They preserve each crate's declared SPDX expression. The technical screening of all 247 package-version records is documented in [the bilingual 2.3.0.0 review](../LICENSE-REVIEW-2.3.0.0.es.md); neither that screening nor these supplements constitute legal advice or distribution clearance.
