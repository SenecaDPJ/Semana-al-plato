Política de privacidad

Versión 2.2.0 · Actualizada el 9 de noviembre de 2026

Datos y almacenamiento

Semana al Plato guarda en este dispositivo la planificación del calendario, los nombres de comidas y alimentos, las categorías y los datos de las recetas (ingredientes, preparación, tiempos y raciones). El calendario se guarda automáticamente en el almacenamiento local del perfil WebView2 de la aplicación. Las preferencias de tema e idioma se guardan por separado en el mismo dispositivo. No se necesita crear una cuenta.

La aplicación no tiene sincronización en la nube, analítica, anuncios ni telemetría. El código de la aplicación no envía menús, recetas ni preferencias a un servidor de Semana al Plato.

Conexiones externas

La única conexión iniciada desde la interfaz es abrir el perfil de GitHub del editor en el navegador predeterminado, después de pedir confirmación. Si aceptas, la navegación y los datos que el navegador comparta se rigen por las políticas de GitHub y del navegador elegido.

La aplicación utiliza Microsoft Edge WebView2. Windows y Microsoft mantienen el runtime Evergreen. El paquete de Microsoft Store está dirigido a Windows 11, que incluye WebView2.

Copias y control

Mis datos → Exportar copia crea un archivo JSON en la ubicación que elijas. Puede contener los datos indicados arriba; guárdalo y compártelo con cuidado. Restaurar copia valida un JSON seleccionado y sustituye los datos actuales después de confirmarlo. La copia no incluye las preferencias de tema e idioma. La aplicación no envía copias fuera del dispositivo.

Conservación y desinstalación

Los datos de trabajo se guardan en el perfil local de la aplicación. En una prueba del paquete MSIX 2.2.0.0 en una VM Windows 11, al desinstalarlo Windows eliminó el directorio local específico del paquete que contenía el perfil y los datos de la aplicación (288 archivos, 67.619.374 bytes antes de la desinstalación). Fue una prueba en una cuenta y no garantiza el mismo resultado en otras cuentas o versiones. Los JSON exportados a otra ubicación y las copias compartidas no se eliminan al desinstalar la aplicación. La aplicación no ofrece una acción independiente para borrar todos los datos.

Menores y datos sensibles

La aplicación no solicita ni necesita categorías especiales de datos personales. Los nombres, recetas y fechas que escribas podrían ser información personal. No incluyas datos que no quieras almacenar localmente o compartir en una copia.

Contacto y cambios

Para contactar con el editor o comunicar una incidencia, utiliza el formulario público de incidencias de GitHub. Las incidencias son públicas: no incluyas datos personales, información sensible ni copias de tus menús.

Esta política se actualizará si cambia la recopilación, el almacenamiento o las conexiones de la aplicación.

Privacy policy

Version 2.2.0 · Updated 9 November 2026

Data and storage

Semana al Plato stores the calendar plan, dish and food names, categories, and recipe details (ingredients, preparation, times and servings) on this device. Calendar data is saved automatically in the app's WebView2 profile storage. Theme and language preferences are stored separately on the same device. No account is required.

The app has no cloud sync, analytics, advertising or telemetry. The app code does not send menus, recipes or preferences to a Semana al Plato server.

External connections

The only connection initiated by the interface is opening the publisher's GitHub profile in the default browser, after asking for confirmation. If you accept, browsing and any data shared by the browser are governed by GitHub's and the selected browser's privacy policies.

The application uses Microsoft Edge WebView2. Windows and Microsoft service the Evergreen runtime. The Microsoft Store package targets Windows 11, which includes WebView2.

Backups and user control

My data → Export backup creates a JSON file at a location you choose. It may contain the data listed above; store and share it carefully. Restore backup validates a JSON file you select and replaces the current data after confirmation. The backup does not include theme or language preferences. The app does not send backups off the device.

Retention and uninstall

Working data is stored in the app's local profile. In one test of the 2.2.0.0 MSIX package in a Windows 11 VM, uninstalling the app caused Windows to remove the package-specific local directory containing the app profile and data (288 files, 67,619,374 bytes before uninstall). This was one test account and does not guarantee the same result for other accounts or versions. JSON files exported elsewhere and copies that have been shared are not removed when the app is uninstalled. The app has no separate action to erase all data.

Children and sensitive data

The app does not request or require special-category personal data. Names, recipe text and dates you enter could be personal information. Do not enter information that you do not want stored locally or included in a shared backup.

Contact and changes

To contact the publisher or report an issue, use the public GitHub issue form. Issues are public; do not include personal data, sensitive information or copies of your menus.

This policy will be updated if the app's collection, storage or connection behaviour changes.
